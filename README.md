# Трекер цен с Claude


[![hexlet-check](https://github.com/viktoriyaturevich-a11y/vibecoding-claudecode-project-388/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/viktoriyaturevich-a11y/vibecoding-claudecode-project-388/actions)

Соберите на Claude-скиллах трекер цен: он сам следит за товарами и присылает в Telegram только значимые изменения.

Учебный проект Хекслета: https://ru.hexlet.io/programs/vibecoding-claudecode


## За чем следит трекер и зачем

Ниша: профессиональный уход за волосами. Трекер следит за ценами на 9 товаров двух брендов в трёх интернет-магазинах:

- **Alterna Caviar** (шампунь, кондиционер, маска) в Dermstore и Ulta;
- **Living Proof** (Perfect Hair Day шампунь и кондиционер, Moisture Rescue маска) в Lookfantastic.

Зачем: чтобы не проверять цены в трёх магазинах вручную и не пропустить скидку или промокод. Трекер за один прогон собирает цены, сравнивает их с прошлым прогоном и присылает в Telegram только значимые изменения: скидка появилась или закончилась, цена изменилась на $0.50 и больше, товар пропал или вернулся в продажу, появился промокод. Правила значимости описаны в [KNOWLEDGE.md](KNOWLEDGE.md).

### Что такое regular_price и sale_price в этих магазинах

- `regular_price`: обычная цена товара, RRP. Если товар со скидкой, в карточке она обычно показана зачёркнутой; в данных страницы Dermstore и Lookfantastic это `price.rrp.amount`. Если скидки нет, это просто текущая цена.
- `sale_price`: текущая цена в карточке, если она ниже RRP (в данных страницы `price.price.amount`). Если скидки нет, поле пустое.
- `promo_code`: код из баннера в карточке товара, например «Use Code: FLASH22». Цена с кодом не считается.

Цены Lookfantastic в фунтах. В файле прогона они хранятся в фунтах вместе с курсом к доллару на день прогона, а в доллары переводятся только для сравнения и вывода.

## Стек

- **Claude Code Skills**: скилл `extract-price` извлекает цены с одной страницы, скилл `tracker` обходит список товаров, сравнивает прогоны и собирает результат.
- **Python** (только стандартная библиотека): `send.py` отправляет сообщение в Telegram.
- **GitHub MCP**: чтение и запись файлов прогонов в приватный репозиторий `tracker-data`, один прогон = один файл `YYYY-MM-DD.json`.
- **Telegram Bot API**: уведомления о значимых изменениях.

## Установка

```bash
git clone https://github.com/viktoriyaturevich-a11y/vibecoding-claudecode-project-388.git
cd vibecoding-claudecode-project-388
```

Создайте в корне файл `.env` (он в `.gitignore` и в репозиторий не попадает):

```
TELEGRAM_BOT_TOKEN=токен_вашего_бота
TELEGRAM_CHAT_ID=id_чата_для_уведомлений
```

Вместо `.env` переменные можно задать в окружении. Для записи прогонов в Claude Code должен быть подключён GitHub MCP с доступом к репозиторию `tracker-data`.

## Использование

Откройте папку проекта в Claude Code и напишите:

```
запусти трекер
```

Трекер обойдёт все 9 товаров, покажет таблицу значимых изменений, отправит сводку в Telegram и сохранит прогон в `tracker-data`. При первом запуске сравнивать не с чем: таблица покажет все товары, а в Telegram придёт `First run, nothing to compare`.

Проверить отправку в Telegram отдельно:

```bash
python send.py "Test message"
```
