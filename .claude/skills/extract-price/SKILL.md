# extract-price

## Контракт

**Вход:** один URL страницы товара.

**Выход:** объект

```json
{ "regular_price": "$40.65", "sale_price": "$36.59", "promo_code": "FLASH22" }
```

- `regular_price` — обычная цена (RRP, до любых скидок).
- `sale_price` — цена по скидке, показанная в карточке товара, или `null`, если скидки нет.
- `promo_code` — сам промокод строкой (например, `"FLASH22"`) или `null`, если промокода нет. Цену с промокодом не считай и не возвращай.
- Обе цены — строки в долларах США в формате `$36.00` (знак `$`, ровно два знака после точки, без пробелов).

## Инструкция

1. **Загрузи HTML страницы:** `curl -sS -L -A "Mozilla/5.0 ..." <URL> -o page.html`.
   Если без браузерного User-Agent страница не отдаётся — добавь его.
2. **Парсинг подключай по необходимости.** Сначала ищи данные простым поиском/regex по HTML. Если структура сложная (много вариантов, вложенный JSON) — разбери HTML Python-скриптом (`json`, `re`, при необходимости `BeautifulSoup`).
3. **Ищи цену только в карточке нужного товара.** Игнорируй блоки «похожие товары», «часто покупают», рекомендации и баннеры других товаров. Если у товара есть варианты (размер, объём), бери тот, чей id/sku совпадает с id в URL.
   Надёжные источники внутри карточки: JSON-LD (`"@type":"Product"` → `offers.price`) и данные страницы вида `price.price.amount` (текущая цена) и `price.rrp.amount` (обычная цена).
4. **Определи цены:**
   - `regular_price` = RRP. Если RRP нет, это текущая цена без скидки.
   - `sale_price` = текущая цена, если она ниже RRP; иначе `null`.
5. **Найди промокод.** Ищи его в карточке товара (блок вроде `pdp-pap-banner`: «Save 22% | Use Code: FLASH22») и верни только код (`FLASH22`). Общий баннер сайта без привязки к карточке — не основание, если в карточке про товар ничего нет. Нет кода — `null`.
6. **Переведи в доллары США.** Если валюта страницы не USD, конвертируй обе цены по среднему курсу из интернета:
   - найди курс «валюта → USD» минимум в 3 независимых источниках (поиск в интернете);
   - возьми среднее арифметическое найденных курсов и округли цену до центов (половина — вверх);
   - в пояснении к результату укажи исходную валюту, использованные источники и средний курс (не в самом объекте).
   Если страница уже в USD — конвертация не нужна.
7. **Отформатируй** цены как `$36.00` и верни объект.
