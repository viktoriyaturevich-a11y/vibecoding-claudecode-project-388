# extract-price

## Контракт

**Вход:** один URL страницы товара.

**Выход:** объект

```json
{ "regular_price": "$40.50", "sale_price": "$36.45", "promo_code_price": "$31.59" }
```

- `regular_price` — обычная цена (RRP, до любых скидок).
- `sale_price` — цена по скидке, показанная в карточке товара, или `null`, если скидки нет.
- `promo_code_price` — цена с применённым промокодом или `null`, если промокода для товара нет.
- Все цены — строки в долларах США в формате `$36.00` (знак `$`, ровно два знака после точки, без пробелов).

## Инструкция

1. **Загрузи HTML страницы:** `curl -sS -L -A "Mozilla/5.0 ..." <URL> -o page.html`.
   Если без браузерного User-Agent страница не отдаётся — добавь его.
2. **Парсинг подключай по необходимости.** Сначала ищи цены простым поиском/regex по HTML. Если структура сложная (много вариантов, вложенный JSON) — разбери HTML Python-скриптом (`json`, `re`, при необходимости `BeautifulSoup`).
3. **Ищи цену только в карточке нужного товара.** Игнорируй блоки «похожие товары», «часто покупают», рекомендации и баннеры других товаров. Если у товара есть варианты (размер, объём), бери тот, чей id/sku совпадает с id в URL.
   Надёжные источники внутри карточки: JSON-LD (`"@type":"Product"` → `offers.price`) и данные страницы вида `price.price.amount` (текущая цена) и `price.rrp.amount` (обычная цена).
4. **Определи три цены:**
   - `regular_price` = RRP. Если RRP нет, это текущая цена без скидки.
   - `sale_price` = текущая цена, если она ниже RRP; иначе `null`.
   - `promo_code_price` = цена после применения промокода, указанного на странице (например, «Save 22% | Use Code: FLASH22»). Считай от той базы, которую назвал сайт (например, «discount applies to RRP»). Если промокода нет — `null`.
5. **Приведи к долларам США.** Если страница не в USD, переведи по актуальному курсу и округли до центов. Если надёжный курс получить нельзя — скажи об этом и укажи, какой курс использован. Исходную валюту и курс упомяни в пояснении к результату, не в самом объекте.
6. **Отформатируй** цены как `$36.00` и верни объект.
