# extract-price

## Контракт

**Вход:** один URL страницы товара.

**Выход:** объект

```json
{ "regular_price": 1999, "sale_price": 1499, "has_credit": true }
```

- `regular_price` — обычная цена (число, без валюты и пробелов).
- `sale_price` — цена по скидке или `null`, если скидки нет.
- `has_credit` — `true`, если на странице есть рассрочка/кредит, иначе `false`.

## Инструкция

1. Открой страницу по переданному URL.
2. Найди на странице обычную цену товара.
3. Если есть цена по скидке (старая цена зачёркнута) — запиши её в `sale_price`, иначе `null`.
4. Проверь, предлагается ли рассрочка или кредит, и выставь `has_credit`.
5. Верни только объект в формате выше, без пояснений.
